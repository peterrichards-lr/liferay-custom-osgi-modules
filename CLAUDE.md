# Claude Code

The line above is an import, not a link: Claude Code expands `AGENTS.md` into
context at session start, so the canonical agent rules are loaded rather than
merely referenced. Do not replace it with a markdown link — a link is prose an
agent may or may not act on, which is the failure this file exists to avoid.
Do not duplicate rules below it either; `AGENTS.md` is the single source of truth.

In-flight task state belongs in `.agent-state.md` (gitignored), never here.
Read that file at the start of a session to resume work.

## Claude-specific notes

- `.claude/CLAUDE.md` and `.claude/rules/` are **blade-generated** Liferay
  workspace rules, regenerated by `blade init -r`. They load automatically
  alongside this file. Do not hand-edit them; `.workspace-rules/` is canonical.
- `main` is protected. Branch and open a PR — never commit to `main` directly.
