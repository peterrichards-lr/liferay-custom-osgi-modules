## 5. What Does Not Belong Here

- **Durable rules and conventions** — they belong in `AGENTS.md`.
- **Liferay workspace guidance** — `.workspace-rules/` is canonical and is
  regenerated by `blade init -r`. Never hand-edit its provider copies.
- **Technical debt and feature work** — tracked as GitHub issues, not as a
  table in this file.
- **What a module ruled out before being written** — that belongs in the
  module's javadoc and its `README.md` entry, per `CONTRIBUTING.md`, because it
  must outlive the task that produced it.
- **Secrets, tokens or credentials** — never, gitignored or not.
